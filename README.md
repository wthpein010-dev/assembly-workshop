# 装配工坊

一个可在电脑和手机浏览器体验的工厂岗位训练游戏。

## 在线体验

- [公开在线版](https://zhuangpei-workshop.polite-chord-7994.chatgpt.site)
- [GitHub Pages](https://wthpein010-dev.github.io/assembly-workshop/)

可快速试玩，也可选择班组，定制角色外观并取名。模拟工位包含带教装内存、独立装配、质检、故障排查和实操认证演示。工友侧有聊天、双人训练、互助、礼物、工坊商店和建设周。用游戏内游玩码可以跨设备读取进度，联机大厅可邀请另一位真实玩家进入交接工位。

电脑可把物料拖到工位目标。手机和键盘可先选物料，再选目标。工位支持旋转内存条、长按压合、检查热点和拖贴质检签。错装可以就地重试，结算会显示准确率、返工、用时与最好成绩。

工序、实操认证和技能津贴均为产品演示。公开版本不需要任何真实员工资料。

## 3D 厂区导览

从首页「先看厂区」或大厅「工坊地图」进入。厂区扩到 50 × 25 米，新增自动化装配区，能看到机械臂、输送线和巡行员工。

总览可右键拖动画面，或点击画面后用 WASD／方向键平移，滚轮缩放。手机用手指拖动平移。V 或界面按钮平滑切换总览和第一人称。

总览可点编号或在「工作台」列表选点。步行用 WASD／方向键移动，点击画面转向，Esc 释放鼠标。手机用左侧摇杆移动，拖动画面转向。

靠近工作台按 E，手机点「操作工作台」。镜头会转到面向台面的第一人称机位，同时打开该台的实操小游戏。选「离开工作台」继续在原工位附近走动。

七张工作台覆盖仓储扫码、主板装配、机箱接线、通电质检、故障诊断、封箱出货和机械臂校准。练习支持拖放，也可以选取物料再点目标。试玩可直接参加。

打开地图右侧「零件回收」可以定位六种零件。三种零件散落在通道里，另外三种由故障机器人掉落。对准机器并在核心暴露时按 F 发脉冲，停机后靠近按 E 拾取。手机可用画面里的脉冲和拾取按钮。

回收的零件可以在主板装配台和自动化校准台的「零件组装」页装入对应插槽。装满会启动该设备，并在场景里亮起指示灯。收集和安装进度保存在游戏存档中。

## 积分兑换店

可直接浏览商品，创建角色后使用工坊积分兑换。虚拟商品进背包，可赠送的物品支持给演示工友附上留言。实物奖励生成模拟核销记录，可在兑换记录里查看。

## 本地运行

需要 Node.js 22.13 或更新版本。项目无安装依赖。

```sh
npm test
npm run build
npm start
```

本地地址为 `http://127.0.0.1:4178`。本地浏览器存档持续保存，本地联机测试数据库随服务退出而清空。线上 Worker 使用 D1。GitHub Pages 提供前端，联机 API 使用公开在线版的 Worker。
